# Corpus sources

Generated by `tools/write_sources_md.py`; do not edit by hand.

Every drawing here was created for this project: hand-written files by
`tools/gen_corpus.py`, the rest drawn by `tools/gen_sources.py` (ezdxf) and
re-saved by other programs with `tools/convert_corpus.sh`. No third-party
drawings are included. Files re-saved by ODA File Converter, or by LibreDWG
from a DWG that ODA made, are not in the public repository: they stay in the
git-ignored `tests/corpus-private/converted/` and the tests use them when
present.

Writers:

- **ezdxf**: ezdxf 1.4.3 (Python, MIT) — original writer, via tools/gen_sources.py
- **oda**: ODA File Converter 27.9 (Open Design Alliance, freeware)
- **freecad**: FreeCAD 1.1.3 (LGPL) — import + DXF export via freecadcmd (writes R14 only)
- **libredwg**: LibreDWG 0.14 (GPL), built from the GNU release — dwg2dxf --as <version>, from a DWG 2018 that ODA made from the source (LibreDWG's dxf2dwg could not read the ezdxf sources). Its R14/R2000 output repeats some VERTEX/ATTRIB/ENDBLK records with duplicate handles; lightable-dxf reports those
