How to read this: each corpus file is written as R12 and R2018 with `lightable generate` (never the source bytes), then re-saved by ODA File Converter (audit on) and imported by FreeCAD. ODA repairs problems silently, so its re-save is compared record by record with our file, discounting what ODA also does when re-saving the original corpus file (tidying objects, renaming anonymous and layout blocks, renumbering polyline vertices). FreeCAD must import every file without error or warning messages. Save-back output is byte-identical to the corpus files, so it needs no separate check.
